# Sketch Manifest

## Design Direction

A warm, independent-shop storefront with Shopify-clear checkout and a compact Linear-like merchant control plane. Public pages are spacious and confidence-building; admin surfaces are dense and operational. Both use LNbits-compatible Vue/Quasar-shaped primitives and bounded design tokens rather than arbitrary CSS.

## Reference Points

- Shopify checkout clarity and persistent summaries
- Linear list/detail efficiency
- Stripe transaction chronology
- Vercel activity/log disclosure
- LNbits Vue 3 + Quasar runtime conventions
- User-provided Perplexity PDF captured under `research/`

## Theme Presets

- Warm Market (default)
- Clean Minimal
- High Contrast
